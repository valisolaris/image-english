イメージイングリッシュ フェーズ1(試作)仕様

サンプル20語で「学習画面・読み上げ・復習」を作り、iPhone で使い心地を確かめる段階の仕様です。Round 1・2 の回答をもとにまとめています。

作るもの/作らないもの

フェーズ1で作る

  • 簡易ホーム(今日の復習数・新しい単語数・「始める」)
  • 学習画面(新しい単語/思い出す)
  • 読み上げ(英語の声、最初はボタンから)
  • 復習の記録と出題(iPhone 本体に保存)
  • サンプル20語(A1)と Pixabay 画像
  • 20語分の画像取得スクリプト

後のフェーズへ

  • ホーム画面に追加・オフライン(フェーズ2)
  • CEFR-J 取り込み・大量データ・画像チェック画面(フェーズ3〜4)
  • 設定画面・書き出し/読み込み・連続日数・統計(フェーズ5)

1日の流れ

  • 復習(期日が来た単語・上限100)
  • →
  • 新しい単語 10語を見て・聞いて・言う
  • →
  • その10語を画像だけで思い出す

1日の区切りは午前4時。開発中だけ「日付を1日進める」ボタンで復習の動きを確かめます。

復習の間隔(Anki方式)

ボタン初めての単語復習中の単語覚えやすさ(ease)
言えなかった3枚後にもう一度 → 言えたら1日後3枚後にもう一度、間隔は1日に戻す−0.20
迷った1日後間隔 × 1.2−0.15
言えた1日後間隔 × ease±0
楽勝4日後間隔 × ease × 1.3+0.15

ease の初期値は 2.5、下限は 1.3。毎回「言えた」を押した場合の出題日:

1日後3日後8日後20日後50日後

決まったこと

D1Pixabay APIキーをフェーズ1で取得し、.env に置く(先に .gitignore へ追加)。20語分を取得するスクリプトを作り、フェーズ3で拡張して使う。
D2画面は学習画面と簡易ホーム。設定はフェーズ1では固定値(新語10・復習上限100・自動読み上げオン・速度ふつう)。
D4サンプルは画像にしやすい語14+しにくい語6。単語リストは実装時に提案し、承認をもらってから例文を作る。
D5例文の単語は変化形でもよい(eat → ate)。例文中の形を target_form に記録し、強調と穴埋めに使う。
D7画像がイマイチなら単語名を伝えるだけ。Claude Code が検索語を変えて取り直す。
D8CLAUDE.md の仕様書パスの崩れ(docs/[SPEC.md](…))を直す。
