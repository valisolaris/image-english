## 4. 確定事項

### D1. 画像(U1)
フェーズ1で Pixabay APIキーを取得し(`.env` の `PIXABAY_API_KEY`)、20語分だけ取得する簡易スクリプトを
`scripts/` に作る。SPEC 7章③と同じ規則(image_query で検索・上位3件を候補・1件目採用・見つからなければ
単語で再検索・なければ null・safesearch 有効・幅480px WebP 50KB目安・出典URLと投稿者名を記録)。
フェーズ3ではこれを拡張して使う。

### D2. 画面(U2)
- 簡易ホーム: 今日の復習数・今日の新しい単語数・「始める」ボタン。
- 学習画面: 4-1 / 4-2(SPEC 4章どおり)。
- 連続学習日数・進み具合・設定画面はフェーズ5。設定値はフェーズ1では固定値
  (1日の新語10・復習上限100・自動読み上げオン・速度ふつう)。

### D3. 復習アルゴリズム(U3: Anki方式)
新しい単語は 4-1 を見たあと、同じ日の 4-2 の評価で最初の間隔を決める:

| 評価 | 新しい単語(初回) | 復習中の単語 | ease の変化 |
|---|---|---|---|
| 言えなかった | 当日もう一度 → 次に言えたら1日後 | 当日もう一度、間隔は1日にリセット | −0.20 |
| 迷った | 1日後 | 間隔 × 1.2 | −0.15 |
| 言えた | 1日後 | 間隔 × ease | ±0 |
| 楽勝 | 4日後 | 間隔 × ease × 1.3 | +0.15 |

- ease の初期値 2.5、下限 1.3。間隔は日単位で切り上げ、前回より最低1日は伸ばす(「迷った」を除く)。
- 1日の流れ: 復習(期日の来た単語、上限100) → 新しい単語(10語)→ 新しい単語の「思い出す」1回。

### D4. サンプル20語(U4)
CEFR-J A1 相当から、画像にしやすい語14語+画像にしにくい語6語(機能語・抽象語、imageability low)。
単語リストは Claude Code が提案し、ユーザーの承認を得てから例文を作る。
CEFR-J ファイルはまだ無くてよい(フェーズ3で取り込む。フェーズ1の level は A1 固定)。

### D5. 例文中の単語の形(U7)
変化形を許可する(eat → ate、apple → apples)。カードに項目 `target_form`(例文中に実際に出てくる形)を
追加し、4-1 の強調表示と 4-2 ヒント2の穴埋めはこの形で行う(最初の1文字は target_form の1文字目)。
`target_form` は `sentence_en` に単語境界つきで必ず1回以上現れること(データ作成時に検査)。
SPEC.md 3章の表への追記はフェーズ1実装時に行う。

### D6. 「言えなかった」の当日再出題(U8)
その日の出題列の3枚後に差し込む。残りが3枚未満なら列の最後に置く。再出題で「言えた」以上なら
D3 の規則で次回日を決める(新しい単語なら1日後)。再び「言えなかった」ならまた3枚後に差し込む。

### D7. フェーズ1の画像差し替え(U9)
ユーザーが iPhone で見て気になった単語名を Claude Code に伝える → Claude Code が image_query を変えて
スクリプトで取り直す(または候補2・3番目に切り替える)。候補を並べる確認画面はフェーズ3で作る。

### D8. CLAUDE.md の修正(U5)
`docs/[SPEC.md](http://SPEC.md)` を `docs/SPEC.md` に直す(2か所)。他の記述は変えない。実装着手時に行う。

### D9. データの形(U6)
- カード ID: `<word>-<pos>`(例: `run-verb`)。CEFR-J には同じ綴りで品詞違いの語があるため。
- `public/data/deck.json`: `{ "version": 1, "cards": [ SPEC 3章の項目 + id + target_form ] }`。
- IndexedDB(DB名 `image-english`):
  - `progress`(キー: カード ID): `state`(new/learning/review)、`due`(学習日 YYYY-MM-DD)、
    `interval`(日)、`ease`、`reps`、`lapses`、`introducedOn`、`lastReviewedOn`
  - `reviewLog`(自動採番): カード ID、学習日、評価(0〜3)、評価前後の interval・ease(フェーズ5の統計用)
  - `meta`: `debugDayOffset`(P5 のデバッグ用。公開版では常に0)
- 「学習日」= 端末の現地時刻から4時間引いた日付(P4)+ debugDayOffset。
