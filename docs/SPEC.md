# イメージイングリッシュ 仕様書 v1

## 1. 目的

- 英会話の練習のための英単語学習アプリ。
- 単語だけでなく **例文とセット** で覚え、**画像** で意味を結びつける。
- 最終目標は「画像(場面)を見て、英語が口から出る」こと。日本語は補助の解説として扱う。
- iPhoneのSafariで、ホーム画面に追加して毎日少しずつ使う。

## 2. 対象の単語

- 出典:CEFR-J Wordlist(東京外国語大学 投野由紀夫研究室)の **A1とA2**(約2,500語)。
- ユーザーが公式サイトからダウンロードしたファイルを `data/source/` に置く。スクリプトはそこから読み込む(ファイル形式は実物を見て判断すること)。
- 出典表記をアプリの「このアプリについて」画面に表示する。
- 出題順:A1 → A2。各レベルの中では「画像にしやすい単語(imageability: high)」を先に出す。

## 3. カードの中身(1単語 = 1カード)

| 項目 | 内容 |
|---|---|
| word | 英単語 |
| pos | 品詞 |
| level | A1 / A2 |
| meaning_ja | 日本語の意味(短く) |
| sentence_en | 例文(日常会話で使える自然な短文。8〜12語程度。その単語を必ず含む) |
| target_form | 例文の中に実際に出てくる形(例:eat → ate、apple → apples)。例文の強調表示と4-2 ヒント2の穴埋めに使う。sentence_en に単語として必ず1回以上現れること |
| sentence_ja | 例文の日本語訳 |
| note_ja | 使い方の短い解説(任意。よく一緒に使う語、似た語との違いなど1〜2文) |
| image_query | Pixabay検索用の英語キーワード(**単語ではなく例文の場面**を表す。例:`woman eating lunch in a hurry`) |
| imageability | high / medium / low(画像で表現しやすいか) |
| image | 画像ファイル名(なければ null) |
| image_credit | Pixabayのページ URL・投稿者名 |

### 例文作成のルール

- A1/A2学習者が読める易しい語彙で書く。
- 会話でそのまま使える文を優先する(一人称・二人称の文、質問文なども混ぜる)。
- 画像にしやすい具体的な場面にする。抽象的な語(副詞・形容詞など)も、その語が表れる具体的な場面の文にする。
- 冠詞・前置詞・代名詞などの機能語は imageability を low とし、例文中心のカードとして扱う。

## 4. 学習の流れ

### 4-1. 新しい単語(インプット:見て・聞いて・言う)

1. 画像、英単語(大きく)、例文(対象の単語を強調表示)を表示。
2. 単語と例文を自動で読み上げる(設定でオフ可)。🔊ボタンで何度でも再生。
3. 画面下に日本語の意味・例文訳・解説を小さめに表示(折りたたみ可)。
4. 「声に出して言ってみよう」と表示。ユーザーは声に出して言い、「次へ」を押す。
5. その日の新しい単語をすべて見終わったら、同じ単語で「4-2 思い出す」を1回行う。

### 4-2. 思い出す(アウトプット:画像を見て英語で言う)

1. **画像だけ**を表示し、「英語で言ってみよう」と表示。
2. 分からないときはヒントを段階的に出せる:
   - ヒント1:日本語の意味
   - ヒント2:例文の穴埋め(対象の単語を `____` にし、最初の1文字だけ表示)
3. 「答えを見る」で英単語・例文を表示し、読み上げる。
4. 自己評価の4ボタンで記録する:
   - 言えなかった / 迷った / 言えた / 楽勝
5. 画像がない単語(image が null)は、画像の代わりに日本語の意味と穴埋め例文を問題として出す。

### 4-3. 復習(間隔反復)

- 過去に学んだ単語は、忘れかけたタイミングで「4-2 思い出す」形式で出題する。
- アルゴリズム:SM-2系のシンプルな方式(Ankiに近いもの)。4段階評価に対応させる。
  - 「言えなかった」はその日のうちにもう一度出す。
- 1日の流れ:**復習を先に** → 新しい単語。

## 5. 画面

1. **ホーム**:今日の復習数・新しい単語数、「始める」ボタン、連続学習日数、全体の進み具合(A1/A2別)。
2. **学習画面**:4-1 / 4-2 のカード。片手で操作できるよう、主なボタンは画面下部に大きく配置。
3. **設定**
   - 1日の新しい単語数(1〜50、初期値10)
   - 1日の復習の上限(初期値100)
   - 自動読み上げ オン/オフ
   - 読み上げ速度(ゆっくり/ふつう)
   - 学習記録の書き出し(JSONファイル)/ 読み込み
   - 学習記録のリセット(確認ダイアログ付き)
4. **このアプリについて**:CEFR-J Wordlist の出典、Pixabay の出典表記、画像ごとのクレジット一覧へのリンク。

### デザイン

- iPhone縦画面に最適化。画像は画面幅いっぱい・大きく見せる。
- ライト/ダークモード対応(iPhoneの設定に合わせる)。
- 文字は大きめ。英語は読みやすいフォント。

## 6. 技術仕様

- **構成**:Vite + TypeScript(フレームワークなし)、`vite-plugin-pwa` でPWA化。
- **オフライン**:アプリ本体とカードデータ(JSON)は初回に保存。画像は表示したものからキャッシュし、加えて「今日のカード」の画像を事前に読み込む。
- **保存**:学習記録は IndexedDB。起動時に `navigator.storage.persist()` を呼んで消えにくくする。
- **音声**:`speechSynthesis`、英語(en-US)の声を優先して選ぶ。iPhoneは最初の再生にタップ操作が必要なので、最初の再生はボタン操作から行う。
- **画像**:幅480px程度の WebP に縮小して `public/images/` に保存(1枚あたり50KB以下を目安)。
- **公開**:GitHub Pages。デプロイ手順をユーザーに案内する。

## 7. データ作成の流れ(開発時のみ)

```
data/source/        ← CEFR-J Wordlist(ユーザーが配置)
data/words.json     ← ① 取り込み結果
data/cards/         ← ② 例文データ(バッチごと、例:a1-001.json)
public/images/      ← ③ 画像
public/data/deck.json ← ④ アプリが読む最終データ
```

1. **取り込み**:CEFR-J から A1/A2 を抽出して `data/words.json` を作る。
2. **例文作成**:Claude Code が 50語ずつ例文・訳・解説・image_query・imageability を作成し、`data/cards/` にバッチ保存する。
3. **画像取得**:スクリプトが Pixabay API(キーは `.env` の `PIXABAY_API_KEY`)で image_query を検索し、上位3件を候補として取得、1件目を採用して縮小保存する。見つからなければ単語で再検索し、それでもなければ null にする。安全検索(safesearch)を有効にする。
4. **画像チェック画面(開発用)**:単語ごとに候補3枚を並べ、タップで差し替えられるローカル専用ページ。公開版には含めない。
5. **統合**:すべてをまとめて `public/data/deck.json` を作る。

## 8. 開発フェーズ

各フェーズの終わりに、ユーザーがiPhoneで確認してから次に進む。

1. **試作**:手作りのサンプル20語(画像込み)で、学習画面・読み上げ・復習の動きを作る。ローカルでiPhoneから確認する方法を案内する。
2. **公開**:GitHub Pages に公開し、iPhoneのホーム画面に追加して動くことを確認する。
3. **データ作成(A1)**:取り込み → 例文 → 画像 → 画像チェック → 統合。
4. **データ作成(A2)**:同じ流れで A2 を追加。
5. **仕上げ**:設定画面、書き出し/読み込み、統計、見た目の調整。

## 9. ユーザーが準備するもの

- CEFR-J Wordlist のファイル(公式サイトからダウンロードし `data/source/` へ)。利用条件も公式サイトで確認する。
- Pixabay のアカウントと API キー(無料)。
- GitHub のアカウント(公開用、無料)。
